# ADR-0016: /write 链路审美去严肃文学偏置——类型小说热闹平权（accepted）

**日期**: 2026-06-01
**状态**: accepted
**触发**: dogfood「01-0531-novel」实测——**无论搞笑还是言情，成稿都"克制、冷静、死板、像严肃文学"**。4 路并行审计（novel-craft 主体 / principles 7 篇分册 / 审修端 / 真人范例库）**独立**得出同一结论。

## 背景：四层自洽叠加的「致冷」链

`show-not-tell`（正确的反 AI 腔）被**全链路层层加码**成"克制 / 留白 / 不说破 / 平静 = 最高级"，把网文合法的**热闹 / 直给 / 情绪外放 / 排比 / 金句 / 内心 OS** 误打成"AI 味 / 低级"。审美底色是**纯文学**的，且**不分体裁**无差别注入——所以搞笑和言情都被拽成严肃文学。四层互相强化：

| 层 | 组件 | 致冷证据 |
|---|---|---|
| ① 最深的根 | `novel-style-reference/corpus/extracts/` | 实际入库 9 部样板 **67% 克制/虐/暗黑、0 爽文甜宠搞笑**；index.json 45 部候选里的热闹类型全部没进 extracts/；选样话术「克制比爆发难写」「温馨≠腻味」「爽文=模板化」；100 条注解清一色「不说破=高级」 |
| ② 手法分册 | `novel-craft/references/principles/` 7 篇 | 共享同 4 部克制流范例；`对话设计`「潜台词>台词」、`心理刻画`「平静>煽情·最高级=什么都没说」把直给/外放打成 AI 味 |
| ③ 生成主体 | `novel-craft/SKILL.md` §一-八 | §5.4「打破对称」灭排比、§3.4 碎句留白当常态、§6.4「不要写全」、§3.1「自由间接>直接独白」、全篇 inline 示例无差别冷调 |
| ④ 审修门禁 | `continuity-editor` + `novel-antipattern` + `rubric` | rubric 9 维**零"过冷"档**、reading_desire 5 sub 无爽点维度（冷稿可全≥7 PASS）；A1/A4 排比、E1 直给、F3 金句无 framing 豁免；blacklist 黑「突然/这一刻/下一秒/无比」中性词；archetype 白名单只认严肃文学腔 → 网文项目 checkpoint Q3 全 NO → 热闹必报 REVISE 被改平 |

共性机制：**只罚过热、不罚过冷**。

## 决策

确立：**类型小说（爽文 / 甜宠 / 搞笑 / 快节奏言情）的热闹、直给、情绪外放、排比、金句、内心 OS 是合法的一等写法，不是 AI 味、也不是低级。** 情绪与语言的温度由**体裁 + 场景**决定，"克制"不是默认底色、也不是最高美学。**保留 `show-not-tell` 内核**（情绪靠承载、不堆形容词标签——防 AI 腔的核心资产）。

## 处置原则（北极星：拿掉噪声 + 喂真人范例 > 加门禁）

- **减法优先**：删 / 翻转 ②③ 层"克制封顶句 / 绝对化铁律"；放宽 ④ 层误杀热闹的反模式 + 剔除 blacklist 中性节拍词。
- **喂真人范例**：① 层 corpus 补搞笑 / 甜宠 / 爽文热范例（最治本）。
- **慎加门禁**：④ 层"反向爽点维度"能用减法（去单向偏冷）解决就不新增 sub。

## 与 ADR-0015 的关系

**ADR-0015（情绪承载温度 / 解除单一温度坍缩）是本 ADR 的首个子实现**——它修的是 narrator_voice 层的单点温度坍缩。本 ADR 是统领，把"去严肃文学偏置"扩展到**生成知识全链路（①②③）+ 审修端（④）**。`#224`（narrator_voice 注入失效）是让前述修复在 /write 端真正生效的前置管线修复。

## 不动的（边界）

`show-not-tell`；真 AI 味反模式（`G1-G3` 主角回避收束 / `D6` 列举式假丰盛 / `D2` 同义换喻 / `B1` 原地踏步 / `C1` 信息倾倒）；schema / 数据管线 / 写权限隔离 / 小说目录结构。

## 可逆性

prompt / docs 改动可逆；范例库补充是**增量**（不删现有克制范例，只补热范例平衡比例）。
