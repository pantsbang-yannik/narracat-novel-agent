# ADR-0019: 读者知情契约——判断同步律与行动判据（accepted）

**日期**: 2026-06-06
**状态**: accepted —— 实施按三端软落地（novel-craft §2.2 / chapter-writer 交付标准 / continuity-editor finding-only），真稿 A/B 验收
**触发**: 2026-06-06 真稿读者反馈（《把酒欢》ch4，仓库根 `docs/report/ab-runs/2026-06-06-chapter-writer-restructure*/`）：悬疑被写成信息遮蔽、主角推理太隐、缺读者锚点、设定词不分层——review 连续 PASS 但读者读不懂重点

## 背景

novel-craft §2.2「该露的露」（世界规则、行动代价、角色目标必须让读者清楚）一直是原则孤儿：无写手自检、无审校维度、无任何下游消费。与此同时，上一轮信号密度校准（治「细节全伏笔化」）引入了 Inference overexposure（推理外露过量）约束——「少写判断句」。两者只有单边落地：写手被持续推向「推理太隐」的极端，产出系统性的「平淡、冷酷、提不起兴趣的冷静感」。

真稿实证（ch4）：主角已把线索串成可行动的判断（「冷东西从北边来、它认我」并据此告诫他人），但正文不让读者拿到这个判断；6 个设定词同时活跃且无锚定。审校端 reading_desire 的 new_information 只度量「抛新信息的量」，不度量「读者能否同步理解」——所以审校全 PASS、读者被排除在理解之外。

## 决策

1. **判断同步律（Judgment sync rule）为读者知情契约的核心律令**：读者可以落后于事实（悬念合法），不可落后于主角已形成的判断——主角每形成一个可指导行动的判断（推理结论 / 威胁评估 / 关联确认），同章内正文必须让读者拿到它。叙述者诡计类写法须由 narrator_voice 层显式 opt-out，不是默认。
2. **行动判据为边界判据**：主角接下来的行动 / 选择依赖该判断 → 必须露，此处直白判断句合法（不算 tell 病、不算外露过量）；不依赖、仅为线索着色 → 受 Inference overexposure 约束。同步律与外露过量自此**成对出现**：同步律管「结论必须到位」，外露过量管「过程不能变成线索注释」。
3. **设定词任务锚定（Setting-term task anchoring）**：设定词在本章承担戏剧任务（被使用 / 构成威胁 / 驱动选择）才出场，首次承担任务时通过动作或后果给读者一次功能性锚定（非词条解释）；氛围词可轻量提及但不展开、不同段堆叠。同时活跃设定词过多属线索密度问题，归 outline 端议题（单章核心唯一性 / 线索预算）治理，不在本契约内。
4. **三端软落地，不动 schema**：
   - novel-craft §2.2 升级为知识 SSOT（律令 + 判据 + 锚定 + 正反范例）
   - chapter-writer 交付标准一句强化 + 指针（高频核心约束需要 agent body 强化层——同日真稿 A/B 实证 Skill 单点注入会失真，见 CHANGELOG 3.10.23/3.10.24）
   - continuity-editor 增「读者理解性」finding-only 审读点（模拟读者问「主角为什么这么做，正文给答案了吗」），不触发 FAIL、不进 retry 主链
   - 不新增 WCP / outline schema 字段：行动判据上下文内生（主角行动就在本章正文里），写手可自答，无需外部数据管线

## 被否决的候选

- **全知情底线**（读者 ≥ 主角全部知情面）：会杀死伏笔——伏笔的定义就是读者当时不注意、事后恍然大悟。
- **仅锚点义务**（只要求关键关联给锚点句、不定同步律）：治标——锚点句的触发时机仍无判准，机制退化为「凭感觉补一句」。
- **新词预算 / 判断句配额**（每章 ≤N）：配额制合规清单，与北极星「拿掉噪声 + 信任模型」相悖，且上限数字拍不准。
- **WCP「读者理解水位」硬字段**：动 schema + plan→写手→审校三端管线，重；且行动判据用不上它。

## 与既有决策的关系

- 与 ADR-0015（情绪承载与克制解耦）、ADR-0016（去严肃文学偏置）同谱系：第三处「单边克制偏置」被真稿证伪——0015 拆「承载 = 收着写」，0016 拆「克制 = 高级」，本 ADR 拆「少判断句 = 干净」。克制类校准自此必须成对声明对边。
- 与 ADR-0018（章末设计存在性）同向：判定标准向真实读者体验对齐。
- 与信号密度校准（CLAUDE.md「句间不连贯反馈的默认诊断」条款）成对：该条款已补对边提醒——压判断句时不得压掉行动依赖的判断。
- CONTEXT.md（仓库根）已登记术语：Reader-knowledge contract / Judgment sync rule / Setting-term task anchoring，与 Inference overexposure 互文。

## 不可重开议题

- 「判断同步是否应该做成每章末固定内心总结段」——否决过：固定位置结算会催生新模板腔（每章末一段总结 = 新的 AI 味），同步时机跟随行动判据分布在正文中。
- 「读者理解性要不要立刻升为 reading_desire 正式 sub_score」——当前为 finding-only；升格与否等几章真稿验证后另议（议题 C 残留部分），不在本 ADR 重开。
