# ADR-0018: 章末收尾判定从「钩子存在性」改为「设计存在性」（accepted）

**日期**: 2026-06-06
**状态**: accepted —— 实施随写作重构系列 issue（narracat-decktop #186）落地，真稿 A/B 验收
**触发**: 2026-06-05 真人小说拆解系列（仓库根 `docs/report/`）：「章末必钩」被一手文本证实是番茄系平台律而非普适律，而现行审校端客观地板把它普适化了

## 背景

continuity-editor 现行「章末钩子地板」是唯一进 REVISE 的阅读吸引力项：末段无「新麻烦 / 新代价 / 未解问题 / 情绪悬停」任一 → 判零钩子 → Still-revise。该地板的本意是拦 AI 的「总结收平」失败模式——这个保护正确且必须保留。但它隐含假设「每章必须有钩子」，三本异质样本的一手拆解证伪了该假设的普适性：

- 《十日终焉》（番茄 1217 章）：每章必钩 + 三机制轮换——地板对番茄系完全成立。
- 《庆余年》（起点 721 章）：开篇约 1/4 章有事件钩，其余大量余韵收尾（意象余韵 / 心理余韵 / 冷笑话 / 平收入睡）——按现地板会被判 REVISE 的章节，恰是经典爆款的合法设计。
- 《她对此感到厌烦》（出版书）：章末以主题落锤为主、钩子移到 beat 间——主题落锤还会撞 novel-antipattern H1（章末点题升华）被双重误杀。

跨平台成立的普适律是「**章末必有设计**」：钩子 / 余韵 / 主题落锤三选，余韵也是设计。

## 决策

1. **审校端地板从「钩子存在性」改为「设计存在性」**：合法集合扩为 新麻烦 / 新代价 / 未解问题 / 情绪悬停 + **余韵设计**（意象定格 / 无言动作收束 / 幽默收尾 / 主题落锤）。「无任何设计的总结收平」仍是 Still-revise 项——对 AI 收平失败模式的硬拦截不放松。
2. **novel-antipattern H1 增加 framing 豁免**：区分「挣来的主题落锤」（落点由本章动作 / 代价 / 情绪弧挣得）与「没挣来的伪深沉升华」（凭空总结、点题口号）。H1 继续拦后者，豁免前者。判据：落锤句是否有本章事件做支撑。
3. **「每章必钩」降为快节奏档位参数**：在平台 / 容器参数表中作为番茄系（追读流）档位的节奏约束表达，不再是普适审校地板。起点系 / 出版书档位余韵收尾合法。

## 与既有决策的关系

- 与 ADR-0009（审修端 craft-first reading_desire）、ADR-0011（阅读吸引力优先）同向：判定标准向真实读者体验对齐，而非向流程纪律对齐。
- 与 ADR-0016（去严肃文学偏置）同构：又一处「单一范式普适化」被一手拆解证伪——0016 拆的是「克制 = 最高级」，本 ADR 拆的是「必钩 = 唯一合法收尾」。
- 与北极星「拿掉噪声」一致：拿掉的是误杀，不是保护——零设计收平仍 REVISE。

## 不可重开议题

未来架构 review 若提出「为什么放宽唯一的阅读吸引力 REVISE 门」，本 ADR 是直接挡回的依据。重开条件仅限：真稿 A/B 验收或 dogfood 数据显示「余韵 / 主题落锤被滥用为收平借口」，且 H1 豁免判据无法区分挣来与没挣来的落锤。

## 可逆性

纯 prompt 改动，可逆。无 schema / 数据管线 / 写权限变更。实施与验收随 narracat-decktop #186（真稿 A/B 盲评「章末继续读意愿」）。
