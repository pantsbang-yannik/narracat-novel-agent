# ADR-0020: 章节问题与线索收敛——单章核心唯一性（accepted）

**日期**: 2026-06-06
**状态**: accepted —— 实施按生产+消费两端落地，真稿 A/B 验收（盲评线索收敛度）
**触发**: 2026-06-06 真稿读者反馈（《把酒欢》ch4）：线索密度过高（猎物南迁 / 兔皮异常 / 阿九预感 / 印记发烫 / 黑牙收摊集中出现无主次）、章节核心不单一、情绪线被设定线压住——根因在 outline 端，写手按硬边界忠实兑现了一份散射式大纲

## 背景

概念阶梯断层：全书有悬问、单元有 `core_question`、场景有 `pressure_point`，**章一级没有同级概念**——`dramatic_focus` 只约束「心动时刻具体」，不约束信息收敛。outline-architect 生成章细纲（scenes 2-5 个）时把「每个场景给一个新异常」当作丰富，线索藏在各 scenes[].pressure_point/outcome 里散射；chapter-writer 硬边界 1 要求守住事件骨架、兑现所有压力点与结果——**大纲塞多少写手写多少，写手没有收敛授权**。ch4 实证：4 场景夹带 5 条独立异常信号，本应只讲「北边有东西靠近，而且它认主角」。

## 决策

1. **章节问题（Chapter question）为章核**：每章只推进或回答一个戏剧问题，补齐概念阶梯（全书悬问 → 单元 core_question → 章节问题 → 场景 pressure_point）。情绪线可并行呈现（dramatic_focus 是章节问题的最强呈现时刻，不是第二个核）。
2. **收敛判据，不设数字预算**：场景的新信息只能作为章节问题的进展或代价出现，或服务情绪线；否则该线索不属于本章，挪去它该在的章。判据能区分「同一问题的两次具体化」（合法）与「两条独立异常」（散射），配额数字不能。
3. **生产+消费两端落地，不动 schema**：
   - **/plan 章细纲模板**新增「## 章节问题」必填节；**outline-architect** 生成 scenes 时执行收敛自检（每个 pressure_point/outcome 服务章节问题或情绪线，否则挪章）。WCP 的 `chapter_outline` 为全文透传，写手直接可读新节，无需 builder/schema 改动
   - **chapter-writer 阶段零**以章节问题为找戏锚（本章的戏 = 章节问题的最强呈现）；**降级授权**：outline 中不服务章节问题的细节信息，写手可压缩为氛围细节、不展开为异常信号——事件照发生（硬边界「事件骨架为真」不破），改变的只是信息的呈现姿态（日常质感 vs 异常信号），与 novel-craft §6.4「其余细节承担场景质感」同根
   - 审校端暂不加检查项（避免新合规清单；读者理解性 finding-only〔ADR-0019〕已覆盖症状面）
   - 旧项目章细纲无「章节问题」节时，写手降级回现状行为（字段缺省兼容）

## 被否决的候选

- **数字预算（每章新线索 ≤N）**：配额制合规清单（与 ADR-0019 同款否决理由），且 N 在高潮章与铺垫章间拍不准。
- **schema 分层标注（clue_tier 主/支）**：动 schema + 三端管线；且「支线索」标签等于给散射发许可证。
- **只改生产端**：存量已细化大纲（ch5-15）的散射无人治，写手继续忠实呈现每条异常。
- **只给写手降级授权**：outline 持续生产散射式大纲，写手每章与大纲博弈，治标。
- **以情绪弧 / value-turn 为章核**：情绪弧管呈现温度不管信息收敛（ch4 有情绪弧仍散射）；value-turn 是场景级概念，章级合成不直观。

## 与既有决策的关系

- 与 ADR-0019（读者知情契约）互补：0019 管「该露的判断必须露」，本 ADR 管「不该进本章的线索不要进」——一个治遮蔽、一个治过载，合起来对应「读者既能看懂、又不会累」。设定词过多的治理出口在本 ADR（Setting-term task anchoring 的数量面）。
- 与硬边界「守住大纲的事件骨架」兼容：降级授权不改变事件真值，只改变呈现姿态——这是「事件骨架不是镜头表」既有原则的信息维度延伸。
- 与北极星「拿掉噪声」一致：收敛判据是排布纪律，不是新检查门禁。
- CONTEXT.md（仓库根）已登记术语：Chapter question；Setting-term task anchoring 的数量治理指向本 ADR。

## 不可重开议题

- 「要不要给线索设数字上限」——否决过，理由同上；若未来真稿显示判据执行不稳，先查 outline-architect 自检措辞再议，不直接回到配额。
- 「降级授权是否违反大纲忠实性」——已裁定：事件骨架为真 + 呈现姿态自由是既有原则（"事件骨架不是镜头表"）的一致延伸，不重开。
