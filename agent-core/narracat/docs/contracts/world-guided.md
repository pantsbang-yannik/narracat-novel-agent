# 契约：world 维度完备性清单 + conflicts[] 结构

> 共享契约 SSOT。消费方（引用须带 `${CLAUDE_PLUGIN_ROOT}/` 前缀）：
> - `agents/world-curator.md`：合成 bible 内容后按 §一 查缺补「留白」，按 §二 返回 conflicts[]
> - `commands/world.md`：步骤 4 确认门按 §二 的 severity 分级处理

## 一、维度完备性清单

world-curator 合成时逐对象对照本清单查缺：任务意图未覆盖的维度，在 bible 内容对应位置写「（留白）」，不编造填充。清单只用于合成端查缺，不用于向用户逐题提问。

### 角色 6 维度

| 维度 | 含义 | 对应 bible 字段 |
|---|---|---|
| 身份 | 是谁、当前处境 | 基本信息 / 背景故事 |
| 欲望 | 想要什么（具体目标物） | 动机与目标 |
| 缺失与致命缺陷 | 缺什么 / 致命弱点 | 能力与弱点 |
| 核心矛盾 | 内心最根本的冲突 | 核心矛盾 |
| 关系 | 与谁绑定 / 对立 | 关系 |
| 弧线 | 预期成长 / 变化方向 | 角色弧线方向 |

### 设定 6 维度

| 维度 | 含义 | 对应 bible 字段 |
|---|---|---|
| 核心规则 | 这个体系怎么运作 | 核心规则 |
| 代价与限制 | 用它要付什么代价 / 什么不能做 | 限制与例外 |
| 势力或冲突轴 | 谁和谁因它对立 | 详细描述 |
| 文化或社会层 | 它如何塑造日常 | 详细描述 |
| 与主角欲望勾连 | 它怎么帮 / 阻主角 | 与其他设定的关联 |
| 独特性 | 它区别于同类设定的一点 | 概述 |

## 二、conflicts[] 结构

world-curator 随 bible 内容一并返回，主会话确认门按 severity 处理。

```
conflicts: [
  {
    severity: "blocking" | "warning" | "info",
    existing_fact: "与之冲突的既有设定（含来源定位）",
    new_claim: "本次新增 / 修改的主张",
    source: "bible 文件路径 | NovelMemory 记录",
    recommended_action: "建议处理（人读提示，非控制流字段）"
  }
]
```

### severity 判级与处理

| severity | 判级 | 确认门处理 |
|---|---|---|
| `blocking` | 与既有设定直接矛盾、无法并存 | 逐条向用户确认：改这项 / 覆盖既有设定 / 取消该项 |
| `warning` | 可并存但有张力，需留意 | 展示提醒，随整体确认一并保存 |
| `info` | 仅补充说明 | 一行记录 |

`recommended_action` 是人读建议，不据它自动合并或丢弃设定。无冲突返回空 `conflicts[]`。
