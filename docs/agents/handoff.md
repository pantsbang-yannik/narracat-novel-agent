# Handoff Template

> 长任务暂停、切换 Agent、准备交给用户继续时使用。复制下面模板并填充，不需要每次小改都写。

```md
# Handoff — YYYY-MM-DD

## Branch

`branch-name`

## Goal

一句话说明本轮目标。

## Completed

- 已完成事项 1
- 已完成事项 2

## Changed Files

- `path/to/file`
- `path/to/other-file`

## Verification

- `command`: 结果摘要

## Known Issues

- 未解决问题或风险；没有就写“暂无”。

## Next Steps

1. 下一步
2. 再下一步
```
