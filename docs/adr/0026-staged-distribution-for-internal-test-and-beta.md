# ADR 0026: 内测/公测走分阶段分发——内测厚客户端、公测建只读语料服务端、引擎上云延后

## Status

Accepted（Decision 第 1、2 步均已落地：白名单打包 2026-07 上线；只读语料服务端 2026-08-05 上线，
范例语料本体已移出本仓与安装包。第 3 步按设计仍显式延后。）

## Context

产品准备发内测包给外部网友。审视打包时发现 `package.json` 的 `extraResources` 把整个 `agent-core/narracat` **原样**复制进 `.app/Contents/Resources/NarraCatAgentCore`——extraResources 不进 asar、是明文目录，"显示包内容"即可读；且 `package-rc.mjs` 走 `prepare-narracat-agent-core.mjs --if-missing`，因目标目录已存在 manifest 而短路，`shouldCopy` 过滤在打包路径**根本不生效**。于是随包外发的实际包含三类性质完全不同的资产（见 CONTEXT「分发资产分级」）：

1. **①创作引擎 prompt**（agents/skills/commands/schemas）——核心 IP。
2. **②第三方版权语料**——`novel-style-reference` 语料的 `paragraph` 字段当时随包携带第三方作品的原文片段，运行时由只读 MCP 工具 `novel_query_style_reference` 按手法×情感检索喂写手。
3. **③研发痕迹**——eval/（3M）、CHANGELOG（192K）、docs、CLAUDE.md/CONTEXT.md、测试、mcp-server 的 node_modules（462M）。

需要拍板：内测怎么安全发，是否为此现在就前后端分离上云。把三类资产摊开后，三个事实定了形：

- **①已有既定姿态**：ADR-0017 已决定本地分发的 Agent Core **不是保密边界**、客户端混淆是 security-by-obscurity（已否决）、要保护 IP 唯一路径是服务端。内测接受 prompt 本地可读与该 ADR 一致。
- **②是独立的版权边界**：分发原文触发复制权+信息网络传播权，与"是否抄袭/是否只作参考"无关，ADR-0017 不覆盖它；而 ADR-0025 把"喂真人范例"定为写作质量头号杠杆——简单删原文会砍掉该杠杆。
- **①和③在当前架构里焊死**：`sdk-runner.ts` 用 `plugins:[{type:'local'}]` 喂 prompt，并 `mcpServers` **本地 spawn stdio 子进程**用 `better-sqlite3` 读写**用户磁盘上的小说文件 + 本地记忆库**，写作过程中边写边改 NovelMemory（ADR-0014）。要把 prompt 搬上服务器藏起来，就得把 SDK 调用搬上服务器；而它跑时要读写用户**本地**数据——够不着。故保护①必然把③（用户创作数据+记忆库）一起拖上云，连带触发一摞尚未拍板的**商业模式决策**。

「反正要建台服务器」只证成了②那台**只读、无状态、碰不到用户数据**的小服务器，不构成现在就把①+③整体上云的理由。ADR-0018 已把"读/展示"侧做成 server-ready（data-source 抽象 + 可插拔传输），最贵的复用地基已铺好。

## Decision

**分发走分阶段，按必要性排序，不让"内测"触发整个后端：**

1. **内测（现在）= 厚客户端**：保留本地引擎运行架构；针对三类资产分别处置——
   - **①prompt**：不加密不混淆（遵 ADR-0017），随包本地可读。
   - **②语料**：维持现状短摘录姿态（REDUCE-RECIPE 红线6：100–300 字摘录 + 机制注解 + 署名，走合理引用），仅随受控 RC 分发，靠**测试者协议**兜底。内测**不动语料**，不为闭门测试砍质量杠杆。
   - **③研发痕迹**：必须在打包产物里清除（eval/CHANGELOG/docs/CLAUDE.md/CONTEXT.md/测试/mcp-server 非运行期 node_modules）。修复 `extraResources` 在打包路径不过滤的缺陷，采**白名单**（默认拒绝：只放运行必需的 agents/skills/commands/schemas/templates/hooks + mcp-server/dist + 运行期依赖），使日后新增内部文件不会再静默外泄。
2. **公测前 = 建一台只读语料服务端**：把②原文移到服务端，写作时按"手法+情感"标签联网取范例，**原文永不落到用户机器、用户小说正文不上传**；走 ADR-0018 已有的可插拔传输缝接入。这是性价比最高、碰不到用户数据的一台服务器，封掉唯一的真版权红线。（替代/补充路径：换原创或授权范例。）
3. **未来（商业模式想清楚后）= 才考虑引擎+③上云保护①**：等商业模式真的想清楚，再重开 ADR-0017 留的服务端边界决策；本 ADR 不预先承诺其形态。内测/公测均不触发它。

## Considered Options

- **为内测现在就前后端分离、引擎上云保护 prompt**：否决（过早、本末倒置）。①被③焊死，为藏一个 ADR-0017 已决定"不用藏"的东西，被迫现在就建整个 SaaS 后端（账号/计费/数据上云/放弃离线），用一次闭门内测触发商业模式决策。
- **内测就把语料删原文（只留机制注解）**：否决（内测阶段）。砍掉 ADR-0025 认定的头号质量杠杆，会让网友评到被削弱的产品、内测信号失真；闭门短摘录风险已足够低。该选项保留为"真要零第三方文本"时的退路。
- **客户端加密/混淆 Agent Core**：否决。重复 ADR-0017 已否决的 security-by-obscurity。
- **分阶段：内测厚客户端 + 公测只读语料服务端 + 引擎上云延后**：采纳。按必要性与可逆性排序，复用 ADR-0018 已铺地基，最小工作量达成"内测安全发 + 公测封版权红线"，把不可逆的商业模式决策留到证据充分时。

## Consequences

- **内测交付清单**（grill 收敛后，开为一组 issue）：①③白名单打包过滤 + 防回归检查；外发 ad-hoc 自签名 + 授权打开教程（未签名 DMG 经网络分发会触发 Gatekeeper 隔离/"已损坏"，Sequoia 右键打开失效需 `xattr`）；Sentry crash 上报（DSN 可内嵌、但须 scrub 小说正文/key/路径 + 首启同意开关）；应用内反馈；BYOK onboarding 友好化；内测声明 + 数据安全提示；内测版过期 + 远程急刹车开关。**测试者协议取消**（点击协议对网友近乎零法律效力，残余风险靠"可信小圈子 + 短摘录"承接，并保留一行内测免责声明）。
- **内测模型接入 = 纯 BYOK**：测试者自带 provider key（默认预填 deepseek，仅需粘贴）。不建额度网关/后端。代价：onboarding 摩擦 + 成稿质量受 provider 影响（deepseek/glm 弱于北极星调校的 Opus/Sonnet），靠 onboarding 引导承接。
- **反馈落 GitHub 的安全约束**：**绝不在客户端内嵌 GitHub token**（Electron 可解包必泄漏）。采"客户端 → 薄 Cloudflare Worker（token 存服务端）→ 自动开 issue"；该 Worker 无状态、不碰用户数据，不构成"为内测建后端"，且是未来语料 API / 网关 / 远程开关 JSON 的复用雏形。Sentry DSN 属只写型上报 key，可安全内嵌，与 GitHub token 不同类。
- **"内测后限制继续使用"只能软过期，不能硬锁**：纯 BYOK 下模型调用客户端直连 provider、不经过你，无任何硬切断手段；硬锁须把调用改走服务端网关（=另一套分发形态，留给未来的商业模式决策）。内测采软过期：远程截止日/最低版本 JSON（可随时改、不重打包）+ 包内烤死硬过期日兜底（抓断网/屏蔽者）；两者均可被改时钟/断网绕过，对可信小圈子够用且 BYOK 不亏成本。该开关与"远程急刹车"二合一。
- **打包链路要改**：`extraResources`/`prepare` 路径改为对 `NarraCatAgentCore` 走白名单导出（默认拒绝），并在打包验收里加一道"产物不含 ③ 研发痕迹"的检查，防回归。
- **②的真红线落在公测**，不在内测；只读语料服务端是公测的前置硬门槛之一，按 ADR-0018 的 data-source 缝实现，渲染/客户端侧不返工。
- **①+③上云保护决策显式延后**，可逆：产品需要保护商业策略时重开 ADR-0017 服务端边界决策，本 ADR 不预先承诺其形态。
- CONTEXT 新增「分发资产分级」「第三方版权语料边界」术语作为本 ADR 的语言锚点。
